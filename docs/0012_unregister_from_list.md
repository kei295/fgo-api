# 0012: サーヴァント一覧ページからの登録解除

## 概要
`/servants`（サーヴァント一覧）でも、所持済みサーヴァントを手持ちから登録解除できるようにする。
従来は登録解除は `/my-servants` のみだった。

## TODO
【☑️】所持済みカードに「✓ 所持済み」と並べて「登録解除」ボタンを表示（`src/app/servants/page.tsx`）
  - `/my-servants` と同様に確認ダイアログを表示し、`DELETE /api/servants/{servant_id}` を実行
  - 404（別タブ等で解除済み）の場合も画面上は未所持に戻す
  - 解除後は所持数・「手持ちに対応する絆礼装」・「手持ちのみ表示」フィルターの結果が即時に更新される
【☑️】登録・登録解除の処理中状態を `pendingIds` に統一し、処理中は該当カードのボタンを無効化
【☑️】`npm run lint` / `npx tsc --noEmit` / `npm run build` すべて成功を確認
【☑️】Playwright + システムのGoogle Chromeで実ブラウザのE2E確認（スクリプトは確認後に削除）
  - 2騎登録 → ダイアログでキャンセルすると変化なし → OKで解除、所持数・絆礼装数が減り「登録」ボタンに戻る
  - 「手持ちのみ表示」中に解除するとカードが消える、リロード後・`/my-servants` にも反映
  - テストで作成したユーザーはすべて削除済み
